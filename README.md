# zhihu_spider 知乎爬虫 README
###  **1. 项目定位 & 功能**

基于 Playwright+MySQL 的知乎数据采集工具，仅用于个人学习研究。
功能：持久登录、爬取话题 / 问题 / 回答 、API 批量采集用户完整资料，数据入库自动去重更新。

### **2.项目文件结构**
zhihu_spider/
├── init_tables.sql         # 全套数据表建表脚本
├──  README.md                # 完整使用说明文档
├──  step1_login.py           # 登录脚本源码
├──  crawl_topics.py          # 话题采集源码
├──  crawl_questions.py       # 问题采集源码
├──  crawl_topic_answers.py   # 回答采集源码
├──  crawl_users.py           # 用户详细信息采集源码
└──  utils.py                 # 公共工具库源码

### **3. 安装 & 运行步骤**

	3.1 安装依赖运行
pip install pymysql playwright scrapling
playwright install chromium

	3.2 数据库配置
MySQL 新建库 zhihu_spider，字符集 utf8mb4
修改utils.py中 MySQL 登录密码
依次执行项目内 7 张数据表建表 SQL

	3.3 初始化登录（首次必跑）运行
python step1_login.py
弹窗扫码登录，自动生成登录凭证。

	3.4 爬虫执行顺序

** 3.4.1 采集关键词话题**
python crawl_topics.py

** 3.4.2 采集话题下问题**
python crawl_questions.py

** 3.4.3 采集回答+评论**
python crawl_topic_answers.py

** 3.4.4 批量采集用户信息**
python crawl_users.py

	 3.5 自研内容与开源框架说明
##### 3.5.1 依赖开源组件说明
本项目基于成熟开源工具框架进行业务开发，所使用的开源组件及其职责如下：

Playwright：微软开源的浏览器自动化工具，提供浏览器启动、页面控制、会话状态导出等基础能力，本项目仅调用其 API 完成扫码登录与会话持久化操作；

Scrapling：开源动态网页采集框架，封装了浏览器动态会话、资源拦截、页面请求等底层能力，本项目基于其浏览器上下文调用知乎后端 API，自动携带接口加密签名；

PyMySQL：开源 Python MySQL 驱动，提供数据库连接、SQL 执行的基础接口；

MySQL 8.0：开源关系型数据库，提供数据持久化存储能力。
以上开源组件均为通用基础工具，仅提供底层技术能力，不包含任何业务逻辑与采集流程。

### **4. 基础使用说明**
所有脚本共用一套登录态，无需重复扫码；
每个脚本顶部可修改单次采集上限、随机延时；
数据库采用ON DUPLICATE KEY UPDATE，重复采集自动更新数据，不产生重复数据；
内置随机休眠、页面滚动加载、弹窗自动关闭防风控。

### 5. 核心原理
页面爬虫：Playwright 模拟浏览器访问，解析 DOM 提取数据；
用户 API 爬虫：Scrapling 复用浏览器 Cookie 调用知乎接口，获取页面缺失的用户教育、工作、居住地等字段；
统一通过 utils 封装函数简化数据库、页面操作。
### 6. 常见问题解决
数据库报错：核对 MySQL 密码、确认 zhihu_spider 库已创建；
页面 403 / 需登录：删除zhihu_state.json、zhihu_profile，重新运行登录脚本；
频繁人机验证：调大脚本内随机休眠时长，减少单次采集数量；
数字全部为 0：页面未加载完成，增大滚动次数。
